# Tv-Stream

Home streaming platform designed for TV, mobile, and web. Supports local network streaming, episodic TV series management, offline downloads, and multi-device access with a Netflix-style UI.

## Features
- **Local Network Streaming**: Access and stream video files across any phone, laptop, or Smart TV on the same Wi-Fi.
- **TV Series & Episodic Management**: Append episodes to existing series, manage seasons, and organize media.
- **Offline Downloads**: Download titles locally for offline playback without an active internet connection.
- **Netflix-Style Theme**: Dark mode cinematic UI with responsive navigation, video player with subtitles and audio tracks, and detailed title modals.
- **Device Sync & QR Code**: Scan QR code on your phone or TV browser to instantly load the local media library.

## Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev
```
